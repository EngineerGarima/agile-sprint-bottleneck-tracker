# 📊 Sprint Delay & Task Tracker

## 🎯 Project overview
I built a simple tracker in **Google Sheets** and **Python** to answer one question:  
*Why do team projects get delayed, and how can we fix it?*

---

## 💡 Quick Highlights (What the data found)

- **84% of tasks** were finished on time.
- **12% of tasks** got stuck ("Blocked"), which caused **47 total hours of delays**.
- **Main Takeaway:** Tasks got delayed because team members were waiting on approvals or handoffs from others.

---

## 🛠️ How a Project Manager Fixes This

1. **Daily Check-ins:** Spend 5 minutes every morning helping team members unstick "Blocked" tasks.
2. **Extra Time Buffer:** Add 1–2 extra days when planning hard technical tasks so the team isn't rushed.

---

## 🧰 Tools Used
- **Python:** Created the project data.
- **Google Sheets:** Built formulas (`COUNTIF`, `SUM`) and simple charts to show the results visually.
